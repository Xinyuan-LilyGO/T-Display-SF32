| 文件                 | 功能                                           |
| -------------------- | ---------------------------------------------- |
| `ui_manager.c/.h`    | LVGL 初始化、UI 线程、锁和消息队列             |
| `ui_navigation.c/.h` | 页面注册、页面切换、当前页面管理               |
| `ui_event.c/.h`      | 定义并分发电池、按键、GPS 等 UI 事件           |
| `ui_theme.c/.h`      | 全局颜色、字体、间距和公共样式                 |
| `ui_context.c/.h`    | 保存 UI 全局状态，例如电量、网络状态、当前页面 |
| `ui_timer.c/.h`      | UI 公共定时任务                                |
| `ui_types.h`         | 页面 ID、事件类型和公共结构体                  |
| `ui_config.h`        | 屏幕尺寸、任务栈、刷新周期等配置               |
